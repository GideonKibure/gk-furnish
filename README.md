# GK furnish

Furniture storefront for GK furnish — handmade chairs, tables, beds and lamps from Mbeya, Tanzania.

## Stack

- TanStack Start / Router
- Supabase (Auth, Database, Storage)
- Snippe payments (optional)
- Tailwind CSS

## Local development

```sh
npm install
npm run dev
```

See [ADMIN_SETUP.md](ADMIN_SETUP.md) for admin CMS, env vars, and Snippe configuration.
